# @min-url/contracts

Shared Kernel workspace package defining canonical DTOs, Zod validation schemas, and error code constants across the `Min-URL` monorepo.

## Subpath Exports

- `@min-url/contracts/errors`: `SLUG_ERROR_CODES`, `SlugErrorCode`
- `@min-url/contracts/dto`: TypeScript interfaces (`SlugDataResponse`, `ShortenAnonymousRequest`, etc.)
- `@min-url/contracts/schemas`: Zod runtime validation schemas
